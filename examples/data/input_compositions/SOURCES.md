`dhz_mineral_compositions.dat` is copied unchanged from Python BurnMan's
`burnman/data/input_compositions` directory for `example_composition.py`.
The reference revision is recorded in
[the reference policy](../../../tests/reference/burnman.json).

The table contains oxide weight proportions, oxygen normalization counts,
mineral names and reference labels for forsterite, pyrope and cummingtonite.
The original header, values and comments are retained.
